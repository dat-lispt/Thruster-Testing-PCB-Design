# Measuring Voltage, Current and Force of thrusters underwater

Components: 
+ $${\color{red} Using \space the \space microcontroller \space ESP32-P4-PICO}$$
+ 2x HX711 Load Cell Amplifiers
+ Voltage Sensor 0-25V 
+ ADS1115 16-Bit ADC 4 Channel with Programmable Gain Amplifier
+ INA219 Current Monitor with I2C interface
+ 2x DEVMO IIC I2C Logic Level Converter Bi-Directional Module 4 Channels 5V to 3.3V Shifter
+ LM 2596 DC-DC Buck Converter Voltage Regulator
+ Blue Robotic Basic ESC
